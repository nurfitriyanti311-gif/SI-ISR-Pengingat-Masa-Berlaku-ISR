# FT-06 Manajemen Template Pesan & Pengaturan Rentang Pengingat

Sumber PRD: Bagian 5 (BL-03), Bagian 6 (FT-06), Bagian 10, dan permintaan iterasi rentang H-1, H-3, H-7

## Tujuan
Admin dapat mengatur tahap hari pengingat aktif (`H-7`, `H-3`, `H-1`), mengaktifkan pemindaian otomatis saat aplikasi dibuka, dan menyunting template pesan multi-kanal tanpa menyimpan kredensial API.

## Alur
1. Admin membuka tab Template.
2. Admin memilih rentang hari pengingat aktif (bawaan tercentang semua: `H-7`, `H-3`, `H-1`) dan status `Proses otomatis saat aplikasi dibuka`.
3. Admin menyunting template WhatsApp, Email, dan Telegram memakai variabel dinamis `{sisa_hari}`, `{nama_klien}`, `{no_isr}`, `{frekuensi}`, `{lokasi_stasiun}`, `{tgl_jatuh_tempo}`, `{tautan_portal}`.
4. Admin menekan "Simpan Pengaturan".

## Data
- `DEFAULT_SETTINGS.reminderMilestones` (`[7, 3, 1]`)
- `DEFAULT_SETTINGS.autoScanOnOpen` (`true`)
- `APP_CONFIG.availableMilestones` (`[7, 3, 1]`)

## Aturan dan rumus
- Minimal 1 tahap hari pengingat harus dipilih dari `[7, 3, 1]`.
- `reminderMilestones` selalu disimpan terurut menurun (`[7, 3, 1]`).

## Input dan validasi
- Pilihan rentang hari pengingat: wajib minimal 1 dipilih; jika kosong tampilkan `"Pilih minimal satu rentang pengingat, contoh: H-7, H-3, atau H-1."`
- Tautan portal perpanjangan: wajib diawali `https://` atau `http://`.
- Seluruh kolom template wajib tidak kosong.

## Tampilan dan teks
- Kotak centang untuk `H-7 (7 hari sebelum jatuh tempo)`, `H-3 (3 hari sebelum jatuh tempo)`, dan `H-1 (1 hari sebelum jatuh tempo)` serta kotak centang `Proses antrean otomatis saat aplikasi dibuka`.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| TMB-06R | Simpan pengaturan bawaan `[7, 3, 1]` dan `autoScanOnOpen = true`. | Pemindaian otomatis langsung memantau H-7, H-3, dan H-1. | Tambahan |
| TMB-07R | Kosongkan seluruh centang rentang pengingat lalu tekan simpan. | Fokus berpindah ke pilihan rentang dengan pesan error dan contoh isian. | Tambahan |

## Di luar lingkup
Penyimpanan API key, token WA Gateway, token bot Telegram, atau kata sandi SMTP.
