# FT-08 Pembaruan Status Tindak Lanjut & Catatan Operator

Sumber PRD: Bagian 5 (BL-05), Bagian 6 (FT-08)

## Tujuan
Operator dapat mengubah status penanganan tindak lanjut ISR dan menyimpan catatan komunikasi dengan PIC perusahaan.

## Alur
1. Operator memilih salah satu baris ISR pada tabel Dasbor dan menekan tombol "Tindak Lanjut".
2. Modal/panel detail menampilkan ringkasan izin, kontak PIC terhubung, pilihan status (`Active (Aman)`, `Warning H-7`, `Dalam Perpanjangan`, `Expired`, `Tidak Diperpanjang`), dan kolom catatan operator.
3. Operator memilih status baru, menulis catatan hasil komunikasi, lalu menekan "Simpan Tindak Lanjut".
4. Sistem menyimpan perubahan ke `localStorage`; status manual `In_Renewal` atau `Not_Renewed` dipertahankan saat pemindaian harian hingga file SIMS baru memperbarui tanggal jatuh tempo ke siklus berikutnya.

## Data
- `APP_CONFIG.followupLabels`
- `licenses[].followupStatus`, `licenses[].manualStatusLocked`, `licenses[].operatorNotes`

## Aturan dan rumus
- Jika operator memilih `In_Renewal` (`Dalam Perpanjangan`) atau `Not_Renewed` (`Tidak Diperpanjang`), `manualStatusLocked` diatur `true` agar pemindaian H-7 harian tidak menimpa keputusan operator.
- Jika file SIMS baru diunggah (`FT-01`) dan `targetExpiredDate` berubah sehingga `Sisa_Hari > reminderDaysBefore`, `manualStatusLocked` dilepas dan status kembali menjadi `Active`.

## Input dan validasi
- Status tindak lanjut: wajib dipilih salah satu dari daftar valid.
- Catatan operator: opsional, spasi awal/akhir dipangkas, maksimal 500 karakter. Jika melebihi 500 karakter tampilkan: `"Catatan maksimal 500 karakter. Ringkas catatan Anda, contoh: PIC konfirmasi bayar BHP minggu ini."`

## Tampilan dan teks
- Panel detail menampilkan informasi stasiun, kontak PIC terkini dari master klien, pilihan status tindak lanjut (radio/select jelas), dan textarea catatan.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| BL-05 | Operator ubah status `Warning_H7` menjadi `In_Renewal` dengan catatan. | Status berubah menjadi `Dalam Perpanjangan` dan tetap bertahan saat tombol "Pindai H-7" ditekan. | PRD BL-05 |
| TMB-09 | Input catatan lebih dari 500 karakter. | Penyimpanan ditahan dan pesan error dengan contoh isian tampil di bawah kolom catatan. | Tambahan |
