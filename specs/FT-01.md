# FT-01 Import & Upsert Laporan SIMS (.xlsx / .csv)

Sumber PRD: Bagian 5 (BL-01, BL-02, BL-04), Bagian 6 (FT-01), Bagian 8 (AC-01), Bagian 9 (TC-01, TC-05)

## Tujuan
Admin dapat mengunggah file laporan ekspor SIMS berformat `.xlsx` atau `.csv` di browser untuk memperbarui data izin dan klien secara otomatis tanpa duplikasi `CURR_LIC_NUM`.

## Alur
1. Admin memilih atau menyeret berkas `.xlsx`/`.csv` pada halaman Impor Data (atau mengunduh berkas contoh `.xlsx` untuk pengujian).
2. Sistem membaca lembar kerja pertama memakai pustaka `xlsx` di browser dan memetakan kolom kunci.
3. Sistem memfilter status aktif (`Granted`, `Granted (Under modification)`), mengarsipkan `Prelim. Canceled` di luar antrean notifikasi, mengelompokkan baris berdasarkan `CURR_LIC_NUM`, dan menentukan `target_expired_date`.
4. Admin meninjau ringkasan hasil pembacaan lalu menekan tombol simpan atau langsung menerapkannya ke penyimpanan lokal `localStorage`.

## Data
- `APP_CONFIG.simsColumnAliases`
- `APP_CONFIG.eligibleStatuses`
- `APP_CONFIG.ignoredArchiveStatusLabel`

## Aturan dan rumus
- Hanya baris dengan `STATUS_SIMF` bernilai `Granted` atau `Granted (Under modification)` (tidak peka huruf besar/kecil) yang ditandai `isEligible = true`. Baris `Prelim. Canceled` disimpan dengan `isEligible = false` dan diabaikan dari antrean notifikasi.
- Beberapa baris dengan `CURR_LIC_NUM` yang sama digabungkan (*grouping*): frekuensi (`FREQ`) dan nama stasiun (`STN_NAME`) yang berbeda digabung dengan pemisah `, `, sementara `rowCount` mencatat jumlah baris perangkat.
- Penentuan `target_expired_date`: memakai `MASA_LAKU` bila terisi; jika kosong memakai `VALIDITY_DATE`; jika keduanya kosong statusnya `Incomplete_Date`.
- Normalisasi `PHONE` mengikuti BL-04 untuk mengisi data awal klien baru (`CLNT_ID`).
- Bila `CURR_LIC_NUM` sudah ada dan tanggal jatuh tempo barunya menghasilkan `Sisa_Hari > 7`, status `Warning_H7`, `In_Renewal`, atau `Expired` otomatis direset ke `Active`.

## Input dan validasi
- Berkas unggahan: wajib berekstensi `.xlsx`, `.xls`, atau `.csv`. Jika format tidak sesuai, tampilkan error: `"Format berkas tidak didukung. Gunakan file Excel (.xlsx) atau CSV (.csv), contoh: laporan_sims.xlsx."`
- Kolom wajib dalam file: `CURR_LIC_NUM` dan `CLNT_NAME`. Jika tidak ditemukan, tampilkan error: `"Kolom wajib CURR_LIC_NUM atau CLNT_NAME tidak ditemukan. Periksa baris header berkas ekspor SIMS."`

## Tampilan dan teks
- Area unggah berkas dengan tombol "Pilih Berkas SIMS" dan tombol sekunder "Unduh Contoh XLSX".
- Ringkasan hasil impor menampilkan jumlah baris terbaca, jumlah izin aktif unik, jumlah arsip `Prelim. Canceled`, data baru, dan data diperbarui.
